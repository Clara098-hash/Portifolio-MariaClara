Como tirar os prints do site para o README:

1. Abra o index.html no navegador (Chrome/Edge/Firefox).
2. Aperte F12 para abrir o DevTools.
3. Aperte Ctrl+Shift+M (ou clique no ícone de celular/tablet) para ativar
   o modo responsivo.
4. No topo do DevTools, escolha o tamanho da tela ou digite manualmente:
     - Desktop:  1440 x 900
     - Mobile:   390 x 844  (tamanho de iPhone)
5. Clique nos 3 pontinhos do DevTools > "Capture screenshot"
   (no Chrome: Ctrl+Shift+P, digite "screenshot", escolha
   "Capture full size screenshot" para pegar a página inteira).
6. Salve os arquivos AQUI nesta pasta "screenshots/" com estes nomes
   exatos (o README já está esperando por eles):

     desktop-home.png       -> topo do site (seção Home) em tela grande
     desktop-projetos.png   -> seção "Projetos" em tela grande
     mobile-home.png        -> topo do site no formato celular
     mobile-menu.png        -> menu mobile aberto (hambúrguer)

Depois de salvar os 4 arquivos aqui, o README vai exibir tudo
automaticamente quando você subir o projeto pro GitHub.
